# OncoEnv

<div align="center">
  <strong>Procedural Bioinformatics RL Environment for Autonomous AI Agents</strong>
</div>
<br/>

OncoEnv is a rigorous, pure-Python reinforcement learning environment built on the OpenEnv framework. It is designed to train and evaluate Large Language Models (LLMs) and autonomous agents in complex oncological data science workflows, specifically single-cell RNA-sequencing (scRNA-seq) analysis, biomarker discovery, and Gene Regulatory Network (GRN) inference.

## 🚀 Overview

The intersection of AI and biology requires agents capable of reasoning through multi-step scientific pipelines. OncoEnv provides a deterministic, procedural biological world state generator that synthesizes realistic tumor biopsy scRNA-seq data with hidden oncogenic perturbations. 

**The Problem:** Existing biological analysis agents are hard to benchmark due to the lack of reproducible environments with dense reward signals and objective ground truths. 
**The Solution:** OncoEnv forces agents to interact with a suite of 40+ simulated bioinformatics tools to recover biological ground truth. It features dense step-wise information-gain rewards, robust metric-based graders (IoU, nDCG, AUROC), and runs entirely on `numpy` and `scipy`—bypassing heavy dependencies like `scanpy` to enable hyper-fast RL training cycles.

---

## ✨ Key Features

- **Procedural scRNA-seq Simulation:** Synthesizes realistic UMI count matrices (200 genes x 500 cells) governed by a preferential-attachment causal GRN, complete with injected low-quality cells and mitochondrial artifacts for realistic Quality Control (QC).
- **Massive Tool Space:** Agents navigate an action space of 40+ bioinformatics tools categorized across Introspection, QC, Normalization, Feature Selection, Dimensionality Reduction, Clustering, Differential Expression (DE), and GRN Inference.
- **Progressive Difficulty Tiers:**
  - *Easy (QC Normalization):* Filter bad cells/genes and normalize. Graded via Intersection over Union (IoU) against ground truth optimal masks.
  - *Medium (Biomarker Discovery):* Discover the hidden oncogenic driver signature. Graded via Normalized Discounted Cumulative Gain (nDCG).
  - *Hard (GRN Inference):* Reconstruct the causal regulatory network. Graded via AUROC + AUPRC.
- **Dense Reward Shaping:** Implements a layered information-gain reward system mapped to a strict biological analysis state machine, guiding agents through the pipeline before applying the final deterministic grader score.
- **Enterprise-Grade Validation:** Includes a comprehensive pre-submission validation suite (`validate.py`) checking pipeline invariants, grader accuracy, procedural novelty, and API contracts.

## 📐 Architecture Overview

OncoEnv acts as a stateful server managing independent agent sessions.

1. **State Generator (`generate_tasks.py`)**: Generates the causal GRN and samples multinational UMI counts with injected dropout and disease perturbations.
2. **Environment Core (`onco_env_environment.py`)**: Maintains the `OncoState`. Parses `OncoAction` tool calls, executes the corresponding pure-Python mathematical transformations on the underlying count matrices, and computes intermediate rewards based on the `OncoRubric`.
3. **Session Manager (`app.py`)**: A lightweight, in-memory session store (Hugging Face Spaces safe) exposing OpenEnv compliant HTTP and WebSocket endpoints to interact with the environment concurrently.
4. **Baseline Inference (`inference.py`)**: A robust LLM agent loop demonstrating how to solve the tasks using dynamic context trimming, state injection, tool repetition guards, and rate-limit backoff logic.

---

## 🧠 System Design Highlights

- **Dependency-Free Bioinformatics:** Re-implemented core `scanpy` functions (PCA, Leiden clustering, Wilcoxon DE, highly variable gene selection) using base `numpy`/`scipy` arrays. This guarantees cross-platform determinism and orders-of-magnitude faster execution for RL rollouts.
- **State Machine Enforcement:** The environment tracks processing history (e.g., `is_normalized`, `has_pca`). The dense reward function relies on this state machine, penalizing out-of-order execution (e.g., attempting clustering before PCA) and guiding the LLM toward correct bioinformatics principles.
- **Deterministic Procedural Generation:** Every `task_id` acts as a seed, guaranteeing that the complex underlying biological state (networks, cell counts, perturbed genes) is 100% reproducible for benchmark consistency.
- **Lightweight Concurrency:** The FastAPI server uses an LRU-style in-memory TTL session cache, allowing multiple agents to train simultaneously against the same deployed environment without database overhead.

## 💻 Installation & Setup

### Prerequisites
- Python 3.10+
- `uv` package manager (recommended for speed) or `pip`

### Local Setup
1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd ONCO-ENV
   ```

2. **Install dependencies using `uv`:**
   ```bash
   uv venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   uv sync
   ```

3. **Run the Server:**
   ```bash
   uv run server
   # Alternatively: python -m onco_env.server.app
   ```
   The server will start on `http://0.0.0.0:7860`.

## ⚙️ Environment Variables

To run the baseline inference agent (`inference.py`), you need to set up the following environment variables.

| Variable | Description | Default |
|---|---|---|
| `HF_TOKEN` | **Required.** Your Hugging Face or OpenAI compatible API token. | `None` |
| `API_BASE_URL` | The LLM API endpoint base URL. | `https://router.huggingface.co/v1` |
| `MODEL_NAME` | The model identifier used by the inference agent. | `llama-3.1-8b-instant` |
| `ENV_BASE_URL` | The URL where the OncoEnv server is running. | `http://localhost:7860` |

## 🧪 Running the Baseline Agent

Once the server is running, you can execute the baseline LLM agent to solve a sequence of tasks (Easy, Medium, Hard).

```bash
# Ensure HF_TOKEN is exported
export HF_TOKEN="your_hf_token"
python inference.py
```
The agent will log its reasoning process, tool execution steps, and final reward score to the console.

### Pre-submission Validation
Verify the integrity of the environment, reward mechanisms, and deterministic generation:
```bash
python validate.py
```

## 📈 Technical Challenges Solved

- **"Poisoned" Signal in Quality Control:** In early versions, mitochondrial (MT-) genes overlapped with transcription factor indices. When agents correctly filtered high-mitochondrial cells, they inadvertently erased the core oncogenic perturbation signal. *Solution:* Re-architected the synthetic generator to strictly isolate the TF network array from mitochondrial gene indices, raising baseline LLM performance on DE tasks significantly.
- **Redundant Edge Budgets in GRN Inference:** Correlation algorithms produced symmetric edges ($A \rightarrow B$ and $B \rightarrow A$), exhausting the agent's limited edge submission budget. *Solution:* Implemented upper-triangular enforcement for mutual information and correlation outputs to strictly emit directed regulatory edges.
- **Grader Blindspots via Feature Selection:** Subsetting to Highly Variable Genes (HVG) destroyed ground truth indices expected by the metric graders. *Solution:* Implemented LLM context hints and pipeline enforcement to dynamically skip HVG selection during evaluation pathways, ensuring the full gene manifold is passed to PCA and clustering.
